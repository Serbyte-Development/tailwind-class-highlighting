# Support

Use GitHub Issues for bugs, compatibility problems, and focused feature requests:

https://github.com/Serbyte-Development/tailwind-class-highlighting/issues

When reporting a highlighting issue, include the Tailwind CSS version, editor/version, operating system, a minimal class example, and the Tailwind CSS entry stylesheet containing `@import "tailwindcss"`.

Tailwind Class Highlighting supports Tailwind CSS v4. Tailwind CSS v3 and earlier are intentionally unsupported.
